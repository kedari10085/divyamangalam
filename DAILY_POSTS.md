# Divya Mangalam — Daily Instagram Posting Schedule

> This markdown file controls what gets posted daily to **[@divyamangalam.info](https://www.instagram.com/divyamangalam.info/)**.
> The automated posting agent reads this file every day at 07:00 AM IST.

---

## How It Works

1. **Scheduled Posts:** You can add specific custom posts below for any date.
2. **Dynamic Fallback:** If today's date has no custom entry below, the agent **automatically calculates today's real Vedic Panchang**, chooses the **Deity of the Day**, generates an **AI sacred artwork image**, and crafts an authentic devotional caption with Sanskrit mantras and link to [divyamangalam.com](https://divyamangalam.com/).
3. **AI Image Generation:** Each post includes an AI-generated 1080×1080 divine artwork prompt (rendered using Pollinations Flux engine).

- **AI Image Prompt:** `[Detailed visual prompt for AI image]`

*When the agent posts this, it will automatically update the status to `[POSTED]`.*
